# 基于 STM32F103 的 MPU6050 跌倒检测系统

基于 STM32F103 与 MPU6050 六轴传感器，实现人体姿态检测与跌倒识别系统。通过 I2C 读取加速度、角速度数据，采用一阶低通滤波降噪，并设计「合加速度 + 姿态角」综合判断的跌倒检测逻辑，最终通过 UART 实时上传至上位机。

## 功能特性

- MPU6050 的 I2C 驱动编写与调试（PB6/PB7，I2C1，100kHz）
- 加速度（±2g）、角速度（±250dps）数据的实时读取
- 一阶低通滤波软件降噪，消除原始数据波动
- 基于合加速度与姿态角综合判断的跌倒检测，区分 **静止 / 正常活动 / 跌倒** 三种状态
- UART 串口实时输出姿态角与跌倒标志位，配合串口调试助手验证

## 硬件清单与接线

| 模块 | 引脚 | 说明 |
|------|------|------|
| STM32F103（F103C8T6/F103VET6 等均可） | — | 主控 |
| MPU6050（GY-521 模块） | VCC→3.3V, GND→GND | 供电 |
| MPU6050 SCL | **PB6** | I2C1 时钟线 |
| MPU6050 SDA | **PB7** | I2C1 数据线 |
| USB 转串口 TX（接上位机） | **PA10** | USART1 RX |
| USB 转串口 RX | **PA9** | USART1 TX（115200） |

> MPU6050 模块的 AD0 引脚接地，器件 7 位地址为 `0x68`。

```
└─────────────┘          └───────────┘
```

## 关键技术点

1. **一阶低通滤波**：`y[n] = α·x[n] + (1-α)·y[n-1]`，系数 `α` 可调（默认 0.2），用于平滑加速度与姿态角曲线、抑制振动干扰。
2. **姿态角解算**：由加速度计计算 Roll / Pitch 倾角，避免磁力计与复杂姿态融合，满足跌倒检测需求。
3. **跌倒判定状态机**：
   - **跌倒**：合加速度明显偏离 1g（自由落体 <0.5g，或撞击 >3.0g），且倾角 >45°（人体躺倒）；
   - **静止**：合加速度接近 1g（±0.15g），且倾角 <20°；
   - **正常活动**：其余情况。

## 编译运行（STM32CubeIDE）

1. 用 STM32CubeMX 新建工程：芯片选 `STM32F103C8Tx`（或你的 F103 型号），时钟 HSE=8MHz、系统主频 72MHz。
2. 开启外设：`I2C1`（PB6/PB7，Standard Mode 100kHz）、`USART1`（PA9/PA10，115200）。
3. 生成工程后，把本仓库 `Inc/mpu6050.h`、`Src/mpu6050.c` 加入工程，并将 `Src/main.c` 的应用逻辑（`while(1)` 内的滤波与检测部分）合并进去，或直接以本仓库 `main.c` 为模板。
4. 编译、烧录，打开串口调试助手（115200），即可看到 `roll/pitch/mag/state` 实时数据。

> 若你的板子晶振不是 8MHz，请在 CubeMX 中按实际修改 `PLLMUL` 等参数重新生成时钟配置。

## 效果示例（串口输出）

```
roll=-1.2 pitch=3.4 mag=1.02 state=1   # 正常活动
roll=2.0  pitch=1.1 mag=1.00 state=0   # 静止
roll=78.5 pitch=12.3 mag=0.45 state=2  # 跌倒
```

`state`：`0`=静止，`1`=正常活动，`2`=跌倒。
